# Images pour le site PrimeContent

Ce dossier contient les images utilisées sur le site PrimeContent.

## Structure des dossiers

- `/brands` : Logos des marques partenaires
- `/clients` : Photos des clients/personnalités
- `/expertises` : Images d'arrière-plan pour les cartes d'expertise

## Nommage des fichiers

### Logos des marques

Les logos des marques doivent être nommés en suivant cette convention :
- Nom de la marque en minuscules
- Espaces et caractères spéciaux remplacés par des tirets
- Extension .png (de préférence avec fond transparent)

Exemple : `ben-jerry-s.png`, `festival-de-monte-carlo.png`

### Photos des clients

Les photos des clients doivent être nommées en suivant cette convention :
- Prénom et nom en minuscules
- Espaces remplacés par des tirets
- Extension .jpg

Exemple : `adil-rami.jpg`, `adriana-karembeu.jpg`

## Recommandations pour les images

### Logos des marques
- Format : PNG avec fond transparent
- Dimensions : environ 300x150px
- Taille de fichier : < 100 Ko

### Photos des clients
- Format : JPG
- Dimensions : 500x500px (carré)
- Taille de fichier : < 200 Ko
- Type : Portrait/photo de profil

### Images d'expertises
- Format : JPG
- Dimensions : 800x600px
- Taille de fichier : < 300 Ko
