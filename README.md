Site web portfolio de PrimeContent, créé avec [Next.js](https://nextjs.org/), [TailwindCSS](https://tailwindcss.com/) et [ShadCN](https://ui.shadcn.com).

## Description

PrimeContent est une plateforme complète de gestion de contenu visuel avec :
- Interface publique de portfolio (photos, vidéos, réalisations)
- Backoffice d'administration complet
- Gestion d'événements, clients et médias
- Système d'authentification sécurisé

## Technologies utilisées

- **Frontend** : Next.js 14 avec App Router, React 18, TypeScript
- **Styling** : Tailwind CSS, Sass, Framer Motion, GSAP
- **Backend** : Firebase Firestore
- **UI Components** : Radix UI, ShadCN/UI
- **State Management** : Zustand

## Structure du projet

- `/app` - Pages et composants Next.js
- `/app/backoffice` - Interface d'administration
- `/app/components` - Composants réutilisables
- `/public` - Assets statiques
