## 🎯 Le Projet

**Dalifilms** est une application web moderne développée pour une agence de création de contenu visuel. Le projet combine une interface publique élégante pour présenter les services et réalisations, avec un backoffice complet pour la gestion de contenu.

### ✨ Fonctionnalités Principales

#### 🌟 Interface Publique

- **Page d'accueil** avec galerie 3D interactive et animations SVG
- **Services Mariages** avec forfaits personnalisés
- **Portfolio Événements** avec fiches détaillées
- **Galeries Photos & Vidéos** organisées par catégories
- **Services Web & Réseaux Sociaux** avec processus détaillés

#### 🔐 Backoffice d'Administration

- **Dashboard** avec statistiques en temps réel
- **Gestion complète des médias** (photos, vidéos, YouTube)
- **CRUD Événements** avec organisation par projets
- **Gestion Clients** avec espaces dédiés et médias privés
- **Centre de Messages** pour les demandes de contact
- **Système d'authentification** sécurisé

---

## 🎨 Points Techniques Remarquables

### 🎬 Animations & UX

- **SplashScreen animé** avec SVG tracé progressif et rotation 3D
- **Galerie défilante** avec préchargement d'images optimisé
- **Transitions fluides** utilisant Framer Motion et GSAP
- **Design responsive** adaptatif sur tous appareils

### 🏗️ Architecture

- **Séparation Client/Admin** avec layouts dédiés
- **App Router Next.js 14** pour les performances
- **State Management** avec Zustand
- **Firebase Firestore** pour la base de données temps réel

### 🔧 Stack Technique

- **Frontend** : Next.js 14, React 18, TypeScript
- **Styling** : Tailwind CSS, SCSS Modules
- **Animations** : Framer Motion, GSAP
- **Backend** : Firebase (Auth, Firestore, Storage)
- **UI Components** : Radix UI, ShadCN/UI

## 📱 Aperçu des Fonctionnalités

### Interface Publique

```
🏠 Accueil          → Galerie interactive, équipe, avis clients
💒 Mariages         → Forfaits, galerie spécialisée
🎉 Événements       → Portfolio avec détails par projet
📸 Photos           → Galerie organisée par catégories
🎥 Vidéos           → YouTube et uploads avec miniatures
💼 Réalisations     → Portfolio général tous projets
💻 Web              → Services développement
📱 Réseaux Sociaux  → Gestion de communauté
```

### Backoffice

```
📊 Dashboard        → Statistiques visiteurs, médias, messages
👥 Clients          → Base clients avec médias privés
🎪 Événements       → CRUD complet avec gestion médias
📸 Médias           → Upload, organisation, catégorisation
💬 Messages         → Centre de contact et notifications
⚙️ Paramètres       → Configuration site et SEO
```
